# Alfred

Alfred (the **A**wesome **L**ibrary **F**or **R**obust **E**xoplanet **D**etection) is a package designed for flexible, user-friendly 
exoplanet detection and characterization. Check out the docs [here](https://alfred-exoplanets.readthedocs.io/en/latest/index.html#).
