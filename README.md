# Alfred

Alfred (the **A**wesome **L**ibrary **F**or **R**obust **E**xoplanet **D**etection) is a package designed for flexible, user-friendly 
exoplanet detection and characterization. Check out the docs [here](https://alfred-exoplanets.readthedocs.io/en/latest/index.html#).

Alfred is pip installable as "alfred-exoplanets". We recommend checking out the more detailed installation instructions in the docs linked above.

If you use Alfred in your work, please cite [Kroft et al. 2026](https://iopscience.iop.org/article/10.3847/2515-5172/ae9165).
